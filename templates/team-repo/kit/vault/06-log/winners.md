## Entry format
```
### W-001 · {{YYYY-MM-DD}} · {{output label}}
- Piece: [[05-outputs/{{output_id}}/{{output file name without .md}}]] ({{unit}})
- Result (client's words or numbers): {{…}}
- Why it likely worked: {{one sentence}}
- Saved as: {{bank entry ID | none}}
```

## Rules
1. Log only what the client reports. Never guess, estimate, or add performance the client did not state.
2. `Result`: the client's words or numbers, verbatim, in quotes.
3. Heading: the date the client reported it, and 1 output label from [[06-log/README]].
4. `Piece`: a wikilink to the output file (full vault path, no `.md`), then the unit in parentheses, as in the format. If the client's message does not identify the piece, ask 1 question with lettered options (a / b / c).
5. `Why it likely worked`: 1 sentence naming 1 pattern (the opening, a story, the format, the topic, or the timing).
